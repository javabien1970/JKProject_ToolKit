How to Install the Add-in
Save the JK_Project_Toolkit.xlam file to a safe folder on your computer where you won't accidentally delete it (e.g., your Documents folder).

Open Excel (a blank workbook is fine).

Go to File > Options.

Click on Add-ins in the left menu.

At the bottom, ensure "Excel Add-ins" is selected in the Manage box and click Go...

Click the Browse... button.

Navigate to where you saved JK_Project_Toolkit.xlam, select it, and click OK.

Ensure "JK Project Toolkit" is checked in the list and click OK.

You should now see a new tab titled "JK Project Toolkit" in your Excel Ribbon.

How to Use the Toolkit
Start a new project: Open the file Project_Data_Template.xlsx.

Tip: Immediately do a "Save As" to save it with your new project name.

Enter Data: Fill in your tasks on the "Main" sheet. Ensure you do not delete the "ConfigVBA" sheet, as the tool needs it to run.

Use the Ribbon: Go to the "JK Project Toolkit" tab in the ribbon to use the tools:

Update Schedule: Calculates dates based on your dependencies and durations.

Render Gantt: Draws the chart on your current sheet.

Export to PPT: Creates a PowerPoint presentation of the plan.

How to Update to a New Version
If you receive a newer version of the JK_Project_Toolkit.xlam file:

Close Excel completely.
